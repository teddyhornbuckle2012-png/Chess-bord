Code Fixes Applied (GitHub Issue #1)

    • Check generation before executing delayed callbacks
    • Cancel pending operations in newGame() and undoMove()
  2. Fix #2: Temporary chess calculations corrupting game state
    • Fixed moveLeavesKingInCheck() to use saveState()/restoreState()
    • Save and restore repetitionPositions length
    • Ensure all state fields are properly restored
  3. Fix #3: Real pawn promotion implementation
    • executeMove() now handles promotion parameter
    • Pawn replaced with selected piece type in engine state
    • Both normal and capture moves support promotion
    • AI defaults to queen promotion
  4. Fix #4: Repetition detection and draw rules
    • Removed halfMoveClock and fullMoveNumber from position key
    • Fixed fifty-move rule threshold: 50 → 100 half-moves
    • Fixed seventy-five-move rule threshold: 75 → 150 half-moves
    • Added checkmate exception to automatic seventy-five-move draw
  5. Fix #5: Duplicate square-click handling
    • Removed individual click listeners from createBoard()
    • Kept only delegated click listener on boardElement
    • Each tap processed exactly once
  6. Fix #6: Chessboard square colors

    • All neighboring squares alternate correctly
  7. Fix #7: Board flipping

  8. Fix #8: Genuine automated tests

  9. Fix #9: Rendering efficiency

  10. Fix #10: AI move validation
